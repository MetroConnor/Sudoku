# Welcome to my Sudoku Application

<h2>How to start the App:</h2>
<ul>
  <li>Download the Project</li>
  <li>Open the main directory "Sudoku" in your terminal</li>
  <li>Use the command "docker compose up --build" to build the app (after you build it once you can start it with "docker compose up" in future)</li>
  <li>Have fun!</li>
</ul>
